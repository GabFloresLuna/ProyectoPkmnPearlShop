# PokéTienda Pearl — Proyecto Full Stack (DSY1104)

Tienda online temática inspirada en la Generación IV de Pokémon (Diamante / Perla / Platino), desarrollada en dos fases para el curso **Desarrollo Fullstack II** (Duoc UC).

## Estructura del repositorio

| Carpeta | Contenido |
|---|---|
| [`fase1/`](fase1) | **Evaluación Parcial 1** — sitio en HTML, CSS y JavaScript (tienda y vistas de administración) y bitácoras de desarrollo. |
| [`app-react/poketienda-entrega/`](app-react/poketienda-entrega) | **Evaluación Parcial 2 — versión de entrega**: migración a React + Vite, reducida (~35 archivos de código). |
| [`app-react/poketienda-react/`](app-react/poketienda-react) | **Evaluación Parcial 2 — versión completa**: misma tienda con más vistas y funcionalidades (checkout con cupones y boleta, panel admin extendido, reportes). |

Cada proyecto de `app-react/` tiene su propio `package.json` y su README con instrucciones.

## Ejecutar rápido

```bash
cd app-react/poketienda-entrega     # o poketienda-react
npm install
npm run dev                         # http://localhost:5173
npm test                            # Jasmine + Karma (requiere Google Chrome)
```

## Tecnologías

React · Vite · React Router · Bootstrap 5 · localStorage (persistencia simulada con CRUD) · Jasmine + Karma + Testing Library.
